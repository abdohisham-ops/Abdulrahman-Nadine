ABDULRAHMAN & NADINE — WEDDING INVITATION WEBSITE

The main website file is index.html. Upload all files in this folder to the root of a GitHub repository, then enable GitHub Pages from Settings > Pages > Deploy from a branch > main > /(root) > Save.

The invitation and countdown work without setup. Guestbook email notifications and private admin view require deploying Code.gs as a Google Apps Script Web App, then replacing the placeholder URL in index.html and Guestbook_Admin.html with the deployed /exec URL.
